# Principles

The design language shared by the menus in this vault. Read these before designing a new menu.

- [Color and contrast](color-and-contrast.md): dark tinted base, value tiers, one accent. Read first; it does most of the work.
- [Depth, glass and glow](depth-glass-and-glow.md): shadows, blur and outer glow, and when each is worth it.
- [Typography and icons](typography-and-icons.md): font choice, size tiers, uppercase headers, icon fonts.
- [Motion](motion.md): what to animate, how fast, and easing.
- [Layout and density](layout-and-density.md): header, tabs, column grid, row anatomy, spacing.
- [Portability across games](portability.md): adapting the language to dark, light and scene-matched art direction, to any resolution or DPI, to sRGB/linear/HDR, and to hosts with no blur or shaders. Read before designing for a game that is not a dark shooter.
- [Avoiding AI defaults](avoiding-ai-defaults.md): the generic choices an LLM falls back on (default blue, uniform boxes, one radius, hype labels, no reduced motion), where the vault overrules them, and a pre-delivery audit. Run the audit before calling a menu or HUD done.
