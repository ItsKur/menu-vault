# References

Case studies of menus and open-source repos. Each links to the principles and widgets it demonstrates.

## New media studies

- [Neverlose — preset manager](neverlose-preset-manager.md): official November 2026 config tutorial; profile toolbar, inline rename, row actions and sharing.
- [gamesense — config page and key fields](gamesense-config-and-key-fields.md): legacy explicit save/load page and bracketed bind tags.
- [Fatality community — NXC config/HUD settings](fatality-nxc-config-and-hud-settings.md): original screenshots of clipboard sharing, scoped reset, HUD settings and themes.

## Menus (from screenshots)

- [Fatality — misc tab](fatality-misc-tab.md): dark navy, hot-pink accent, header icon tabs, three-column group boxes. Source of the rich style baseline's default (sampled) values.

- [Fatality — first tab, grey and indigo](fatality-rage-tab.md): **the owner's favourite colour scheme** and their reference for an opaque menu. The same layout in charcoal grey and deep indigo with a pink-red accent; three surface levels, inset controls.

- [gamesense — main menu](gamesense-menu.md): near-black, flat, 1 px lines, icon rail, hue stripe, square checkboxes, one user accent. A distinctive named style: use it when a request asks for gamesense or skeet. Five captures plus a recreation repo's drawing code.

- [Neverlose — hotkey menu, tooltips and list popup](neverlose-popups.md): right-click hotkey menu with hover submenus, tooltips docked beside the menu, a "⋯" list popup. The vault's reference for keybinding and popups.

- [Neverlose — five colour themes](neverlose-themes.md): one layout in lime, blue, navy, pink and a light translucent theme; three group-box styles; the Edit Style colour-role list; a bind popup; and **a model preview with highlighted bone points**. The owner's reference whenever transparency comes up.

- [Neverlose — visuals page with model preview](neverlose-visuals-page.md): the full shell (brand block, grouped sidebar, profile chip, cards with swatch + control rows) and a live model preview.

- [Neverlose Recurrence — menu (Figma concept)](neverlose-recurrence-menu.md): a community redesign of the neverlose shell in Figma: three stacked glass sheets with one 5 % hairline edge, blue accent, value boxes, text fade for long combos. **Exact values** decoded from the `.fig`. The matching HUD is in Visuals.

- [Pink sidebar menu — feature tab](pink-sidebar-menu.md): near-black neutral grays, pale pink accent, grouped sidebar, keybind icon on each row, sliders with value boxes, and a keybind-animation settings panel. Read for a restrained, almost colorless look.

HUD and in-world screenshots go in [Visuals](../visuals/INDEX.md), not here.

## Open-source repos

- [neverlose-ui](neverlose-ui.md): standalone D3D11 + ImGui recreation of the neverlose CS2 menu. Best code reference for blur, shadows and animated widgets.
- [velocity.cat — main menu](velocity-cat-menu.md): frosted-glass menu with an icon rail, sliding-pill sub-tabs, untitled cards, "⋯" row popups, settings search and five theme presets. Exact values read from source. The **minimal baseline** look; also the reference for translucent, glassy menus.
- [Starter bases](starter-bases.md): plain ImGui menu shells to build on (xo1337/imgui-external-base, imgui-standalone).
- [Fatality CS2 — menu drawing code](fatality-cs2-source.md): exact palette, fonts, sizes, every control's drawing details and animation timings for the owner's favourite look, read from a leaked source (values only, no code copied). Read before rebuilding the Fatality style.
- [Lumin framework — main menu](lumin-framework-menu.md): rounded, neverlose-like framework: charcoal-violet surfaces, pale periwinkle accent, title + description rows, ring-knob toggles that keep a dark track. Exact values from source.
- [NL loader — dashboard and modal](nl-loader-dashboard.md): neverlose loader recreation: near-black with muted blue, outlined cards, blur past the fold and behind the modal, a tuned window-open animation. Read for launcher windows and motion timings.
- [imgui-menu-clone](imgui-menu-clone.md): screenshot-to-menu agent workflow; read its detail checklist (ring knobs, overhang, track fill) and ImGui pitfalls before cloning a reference.
- [Dear ImGui](dear-imgui.md): the library itself, its demo/style editor, and the community gallery.
