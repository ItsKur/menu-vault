# Starter bases

Plain menu shells to start a design from. Check any base's contents before using it: some "menu bases" in the same search results bundle hooking or memory libraries, which are out of scope for this vault.

## xo1337/imgui-external-base

- https://github.com/xo1337/imgui-external-base
- An external Dear ImGui menu base; the author pitches it as clean, readable starter code with nothing special in it.
- Use as: a minimal window to drop the [Style baseline](../implementation/imgui-style-baseline.md) and custom widgets into.

## imgui-standalone

- https://github.com/sxzxs/imgui-standalone-main
- D3D11 standalone window; builds as EXE or DLL. **Build the EXE** for a self-contained design sandbox.

## Skip for this vault

Android "mod menu template" repos (e.g. Zygisk-based ones) bundle hooking libraries (Dobby, KittyMemory); not UI-only.
